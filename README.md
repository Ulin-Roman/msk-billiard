# Свояки Сурмина — школа бильярда

Отдельный новый проект. Не связан с ArtBalkon и не использует его файлы, хостинг или настройки.

## Просмотр

Запуск: `npm run dev`, затем http://127.0.0.1:4173.
Статический сайт находится в `dist/`. Сборка и внешние зависимости не требуются.

## Содержание

Адаптивный одностраничник: Илья Сурмин на первом экране, три дисциплины, программа обучения, все разовые цены и абонементы с переключением формата и длительности, тренеры, сертификаты, отзывы, клубы, дипломы, FAQ и контакты.

Тексты, тарифы и оригинальные фотографии перенесены с https://msk-billiard.ru/ 6 октября 2026 года. Изображения принадлежат исходному сайту; открытая лицензия не заявляется. В отзывах использованы сокращённые версии с сохранением смысла. В сроках абонементов использована страница стоимости (45/75 дней), а не устаревшая формулировка FAQ про 40 дней.

Источники: `/`, `/disciplines/`, `/stoimost-uslug/`, `/nashi-trenery/`, `/otzyv/`, `/bilyardnye-kluby/`, `/contact-us/`, `/podarochny-sertificat/`.

## Запись

Форма составляет сообщение и открывает WhatsApp школы. Отправку подтверждает сам посетитель. Данные не хранятся на сервере. Также доступны действующие телефон, email, Telegram и ВКонтакте. Исходный обработчик WordPress не подключён.

## Файлы

- `dist/index.html` — разметка и содержание.
- `dist/style.css` — оформление и адаптация.
- `dist/app.js` — цены, меню, запись и просмотр дипломов.
- `dist/assets/` — локальные оригинальные изображения.
- `server.mjs` — локальный сервер просмотра.

Проверка JavaScript: `npm run check`.
